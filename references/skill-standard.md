# Skill 建造标准（skill-standard）

> 熔炉产出的每个 Skill 必须符合此标准。来源：Anthropic Agent Skills 官方规范 + 归藏范式蒸馏。

## 一、骨架三段式（固定结构）

```
skill-name/
├── SKILL.md        # 必需。frontmatter + 工作流主体
├── references/     # 按需加载的详细规范（模型需要时才读，省 token）
├── assets/         # 模板、种子文件（可直接拷贝使用的完整产物）
└── scripts/        # 可选。辅助脚本
```

原则：**SKILL.md 是导航图不是百科全书**。主体控制精炼；超过 100 行的细节规范移入 references，在 SKILL.md 里写明"何时读哪份"。

## 二、frontmatter（技能的第一质量杠杆）

```yaml
---
name: skill-name          # 小写字母+连字符，与目录名一致
description: >            # 决定模型何时选中它——必须包含：
  一句话定位。            # 1. 它是干什么的
  当用户说"原话1""原话2"时使用。  # 2. 触发词矩阵：用户真实说法，中英双语
  当任务涉及{场景关键词}时适用。   # 3. 场景关键词
---
```

- description 写完后自检：把目标用户可能说的 5 句话列出来，逐句问"凭这个 description 模型会选中它吗"
- 禁止只写功能不写触发场景——那是说明书，不是触发器

## 三、SKILL.md 正文段落模板

按此顺序组织：

1. **来源识别段**（HTML 注释）：作者、版本、日期、来源仓库。注明"不写进生成物"
2. **这个 Skill 做什么**：一句话 + 可选模式。有审美/质量要求时给**锚点**（"像 XX 一样"——用已知参照物锁死标准）
3. **何时使用 / 何时不使用**：两组明确场景。缺了"何时不用"，模型必误触发
4. **工作流程（Step 分步）**：
   - Step 0 视情况放环境检查/更新检查
   - **Step 1 永远是澄清**（信息不足时禁止基于猜测开工）；澄清问题列表化，注明"一次最多问 N 个"
   - 中间步骤产出**中间产物落盘**（大纲-v1.md 等），给用户校准点
   - 最终步骤含**预检机制**：列出"最常犯的错"+ 检查方法
5. **环境适配分支**：不同 Agent 环境的交互机制差异（如结构化提问工具 vs 普通对话），显式写明；不假设某平台机制在他处可用
6. **references 索引**：哪份文件、什么时候读

## 四、防御性写作清单

写每个 Step 时自问："模型在这一步最常犯什么错？"把答案写成显式禁令或检查：
- 占位符类产物 → "拷贝后第一件事 grep `[必填]` 确认全部替换"
- 模板类产物 → "使用的每个类名/组件必须在模板里有定义，先读模板再写"
- 外部数据类 → "读不到就停下来说明，禁止编造"

## 五、references 写作规范

- 每份文件一个主题，头部一句话说明"何时读我"
- 清单分级：P0 致命 / P1 严重 / P2 一般 / P3 建议
- 示例必须完整可直接拷贝，不写"此处省略"

## 六、禁令

- 禁止在 SKILL.md 堆所有细节（token 浪费且模型抓不住重点）
- 禁止无中间产物校准的长流程
- 禁止给无限自由度（"任意风格均可"=质量失控）
- 禁止平台私有机制写进本体（平台差异去 platform-adapters 层）
